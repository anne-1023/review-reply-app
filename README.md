＃口コミ返信AI生成アプリ

＃＃概要
Google Gemini APIを利用し、口コミを入力すると店舗用の自然な返信文を生成するwebアプリです。

＃＃制作目的
店舗の口コミ返信業務を効率化するために個人開発しました。

＃＃使用技術
Next.js
React
Node.js(開発環境)
Tailwind CSS
TypeScript
Gemini API
Vercel

＃＃主な機能
口コミの入力
AIによる返信文の生成
ブラウザから利用可能

＃＃工夫した点
AIらしい定型文やオウム返しにならないようにプロンプトを調整し、店舗スタッフがそのまま使用できる自然な返信分を生成できるように改善
そのまま店舗利用できる自然な文章を目指して改善
シンプルで使いやすいUIを意識して作成

＃＃デモ
https://review-reply-app-beta.vercel.app/
